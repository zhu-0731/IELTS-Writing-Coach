# IELTS Writing Coach

IELTS Writing Coach 是一个本地运行的雅思写作训练工具，目标不是替学生生成整篇范文，而是帮助学习者在真实写作过程中发现问题、积累表达、完成针对性练习。

项目面向已经开始备考 IELTS Writing、但经常卡在审题、展开、表达替换和语法细节上的用户。它把一次写作拆成“写作 - 诊断 - 积累 - 练习 - 复盘”的闭环，让用户保留自己的原文，同时通过 AI 获得结构化反馈和可重复训练的材料。

## 设计原则

- **本地优先**：作文、诊断、练习记录、API Key 都保存在本地 SQLite 数据库中。
- **教练而不是代写**：AI 默认提供审题、逻辑、表达、句型和练习建议，不直接替用户完成整篇作文。
- **基于用户原文训练**：诊断和练习都围绕用户自己的作文生成，避免脱离个人问题的泛泛建议。
- **可复盘**：历史作文、历史诊断、练习记录和语言积累都可以回看和管理。
- **可配置模型**：支持 OpenAI-compatible API，可为“全文诊断”和“练习生成”分别设置模型。

## 核心功能

### 写作工作台

- Task 1 / Task 2 写作入口
- 题目、题型、图片题目上传
- 实时字数统计和目标进度
- 写作计时器
- 自动保存草稿
- 可折叠 AI 侧边栏
- 一键开始新写作并清空当前工作台状态

### AI 侧边栏

- **AI 提示**：根据语言资源库推荐句型、词块、表达和逻辑模板
- **Idea Coach**：帮助拆解题目、生成中文立场和段落逻辑链
- **Expression Coach**：把中文想法转换成低风险、推荐、高分三档英文表达
- 提示卡片支持“已使用 / 太难了 / 不适合这题”等反馈，用于调整资源掌握度

### 作文诊断

- 独立三栏诊断页面
- 左侧按文章结构和逻辑块展示原文
- 中间按逐句、逐段展示修改点
- 支持拼写、语法、表达、逻辑四类筛选
- 右侧展示系统推荐积累，用户可选择、编辑并加入语言资源库
- 诊断结果完整保存，刷新页面不会重新诊断
- 历史记录中可查看多次诊断，并支持右键删除诊断记录
- 诊断拆分为多个 AI 任务：审题短输出 + 逐段诊断，降低模型输出过长导致的 JSON 截断风险
- 部分任务失败时支持只重试失败任务

### 语言资源库

- 从诊断建议和用户选择中积累句型、搭配、表达
- 按类型、掌握度筛选
- 支持删除资源
- 资源可用于写作提示和练习题生成

### 练习系统

- 根据最新诊断和语言资源生成练习
- 支持填空和句子默写
- 支持多种可接受答案
- 如果用户输入原始或较弱表达，会提示进行表达替换
- 支持 AI 申诉判题
- 未完成练习可继续
- 已完成练习可查看记录和错题重练
- 练习记录支持删除

### 历史记录

- 查看所有作文草稿
- 恢复历史作文到工作台
- 查看最近诊断摘要
- 查看同一篇作文的多次诊断
- 删除作文时同步清理相关诊断
- 导出 Markdown

### 设置

- 配置通用 OpenAI-compatible API
- 为全文诊断和练习生成单独指定模型
- 修改个人目标、主要任务、写作卡点和模板偏好
- 数据重置

## 技术结构

```text
IELTS/
├── backend/          # FastAPI + SQLite
├── frontend/         # React + TypeScript + Vite + Tailwind CSS
├── docs/             # 产品计划、协作协议和工作记录
└── README.md
```

### 后端

- FastAPI
- SQLite
- OpenAI-compatible LLM Provider
- 主要数据表：
  - `settings`
  - `feature_settings`
  - `user_profile`
  - `essays`
  - `diagnoses`
  - `language_resources`
  - `practice_sessions`
  - `practice_items`

### 前端

- React
- TypeScript
- Vite
- Tailwind CSS v4
- React Router
- 本地状态和 `sessionStorage` 结合，用于草稿、诊断页恢复和工作台状态保持

## 启动

### 后端

```powershell
cd backend
conda activate ielts
uvicorn main:app --reload
```

后端运行在：

```text
http://127.0.0.1:8000
```

### 前端

```powershell
cd frontend
npm run dev
```

前端默认运行在：

```text
http://localhost:5173
```

## 首次使用

1. 启动后端和前端。
2. 浏览器打开 `http://localhost:5173`。
3. 完成首次设置问卷。
4. 进入“设置”页面配置 API Key 和模型。
5. 回到首页或工作台开始写作。

## API Key 与数据说明

API Key 仅保存在本地 SQLite 数据库：

```text
backend/data/ielts.db
```

该数据库文件不会提交到 Git。项目 `.gitignore` 会排除数据库、虚拟环境、构建产物和本地配置文件。提交代码前请确认没有包含 API Key、数据库文件、`.env` 或其他敏感数据。

## 当前状态

项目已经具备完整的本地写作训练闭环：

1. 写作工作台完成作文输入和草稿保存。
2. AI 侧边栏提供审题、表达和提示辅助。
3. 全文诊断提供三栏式逐句、逐段反馈。
4. 语言资源库支持选择、编辑和管理积累。
5. 练习系统支持生成、继续、查看记录、错题重练和申诉判题。
6. 历史记录支持作文恢复、诊断查看、诊断删除和 Markdown 导出。
